# Organizer - Color Palette

## Design System

### Primary Accent (Indigo)
- **Primary**: `#3730a3` - CTA, active states, focus
- **Primary hover**: `#312e81` - Darker on interaction
- **Primary muted**: `#e0e7ff` - Quick energy tint
- **Primary subtle**: `#f5f3ff` - Light backgrounds

### Secondary Accent (Amber)
- **Secondary**: `#b45309` - Ritual, remove-from-focus
- **Secondary muted**: `#fef3c7` - Warm highlight
- **Secondary subtle**: `#fffbeb` - Wrap-up gradient base

### Neutrals
- **Surface**: `#fafaf9` - Page background
- **Surface elevated**: `#ffffff` - Cards
- **Border**: `#e7e5e4`
- **Border subtle**: `#f5f5f4`
- **Text**: `#1c1917` - Primary
- **Text secondary**: `#57534e` - Metadata
- **Text muted**: `#78716c` - Labels
- **Text ghost**: `#a8a29e` - Placeholders

### Energy Modes
- **Deep**: `#312e81` / bg `#eef2ff` - Calm, serious
- **Quick**: `#4338ca` / bg `#e0e7ff` - Brighter accent
- **Light**: `#a8a29e` / bg `#fafaf9` - Ghost-like, desaturated

### States
- **Done**: `#6b7280` / bg `#f5f5f4` - Reduced saturation, calm
- **Overdue**: `#9f1239` / bg `#fff1f2` - Soft warning

## Usage

- Primary CTA: Add button, main actions
- Secondary: Ritual section, secondary emphasis
- No pure black except primary CTA
- Completion: desaturate, increase calm
- Hover: soft color introduction, never abrupt
